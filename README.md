# TraceLens

**操作と意図を、実装につなぐ** — ブラウザ操作の調査・記録ツール（プロトタイプ v0.1.0）

人間がブラウザで行った操作を、対象要素・画面構造（DOM）・操作後の画面・観測時刻・人間が書いた意図や成功条件と関連づけて保存し、AIコーディングに渡せるZIPとして出力する Chromium 向け拡張機能（Manifest V3）です。記録したシナリオを、再生で確かめながら調整することもできます。

- 記録はすべてブラウザ内（IndexedDB）に保存し、**外部へ送信しません**。外部API・外部フォントも使いません。
- 記録するのは、**ユーザーが記録を開始した1つのタブだけ**です（新しいタブへの切り替えは任意設定）。
- 再生は記録したシナリオを対象ページで実行し、画面変化を観測する機能です。**業務処理の完了や成功を確認するものではありません。**
- AI API 連携、クラウド同期、認証、チーム共有、Selenium コード生成は対象外です（収集側と、成果物を使う自動化技術は分離しています）。

## 1. 開発・ビルド

必要環境: Node.js 20 以上（22 で確認）。

```bash
git clone https://github.com/Hoyuma/TraceLens.git
```

```bash
cd TraceLens
```

```bash
npm install
```

```bash
npm run build
```

`dist/` に拡張機能一式が生成されます。

| コマンド | 内容 |
|---|---|
| `npm run build` | 配布用ビルド（`dist/`） |
| `npm run typecheck` | 型検査 |
| `npm test` | 単体テスト（入力の集約、機密値の除外、セレクター、エクスポート、保存、再生の計画・ページ内の操作、レビュー画面、取り込み、画像編集、グループと変数など） |
| `npm run mock` | 模擬業務ページを起動（http://127.0.0.1:4173/login.html） |
| `npm run e2e` | 実ブラウザでの通し検証（テスト用ビルド `dist-e2e/` を使用。Playwright と Chromium が必要） |
| `npm run verify:real-permissions` | 配布用ビルドの権限フロー検証（Linux + Xvfb + python3 + ImageMagick が必要） |

`dist-e2e/` は自動テスト専用で、`host_permissions: <all_urls>` を事前付与しています（ツールバーアイコンのクリックを自動化できないため）。**利用者には `dist/` を導入してください。**

`npm run e2e` は Windows では PowerShell など通常のシェルから実行します。Playwright は依存に含まれないため、`npm install --no-save playwright` と `npx playwright install chromium` で導入してください（2026-11-17 の確認手順）。

## 2. Edge / Chrome への導入

Chrome 116 以降、または同等の Chromium 系 Edge を想定しています。

1. `npm run build` を実行する。
2. 拡張機能の管理ページを開く。Chrome: `chrome://extensions` / Edge: `edge://extensions`
3. 「デベロッパー モード」（Edge は「開発者モード」）をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」（Edge は「展開して読み込み」）で `dist` フォルダーを選ぶ。
5. ツールバーの拡張機能メニュー（パズルのアイコン）から TraceLens をピン留めする。

インストール時に要求する権限は `activeTab` / `scripting` / `sidePanel` / `storage` / `unlimitedStorage` のみで、サイトへのアクセス権は要求しません。再生や「全サイト」の記録は、使うときに任意の権限を求めます（[docs/guide.md](docs/guide.md) 参照）。更新時は `npm run build` の後、拡張機能の管理ページで再読み込みしてください（記録中のセッションは「中断」になりますが、保存済みの記録は残ります）。

## 3. 模擬業務ページ

実際の業務システムがなくても試せる、小さな模擬ページを `mock-site/` に同梱しています（TraceLens 本体とは独立。本体側に勤怠固有のロジックはありません）。

```bash
npm run mock
```

http://127.0.0.1:4173/login.html を開きます。対象日、PJ 選択、PJ に応じて遅れて更新される工程選択、工数入力、行追加、保存と完了メッセージ、必須入力エラー、登録済みデータの再表示、SPA 形式の画面切り替え、パスワード欄、同一オリジン iframe、open Shadow DOM を含みます。

## 4. 使い方（概要）

1. 記録したいタブを表示し、ツールバーの **TraceLens アイコンをクリック**（サイドパネルが開き、そのタブへのアクセスが許可されます）。
2. パネルでプロジェクトとシナリオを作成し、「記録を開始」。
3. 普段どおり操作する。必要に応じて「画面を保存」「ページ全体」「要素を画像で保存」、要素の注記、直前の操作へのメモ。
4. 「一時停止／再開／終了」。
5. 「レビュー画面を開く（編集・再生・取り込み）」で確認・編集・注記・除外・画像の編集 → 必要なら再生で確かめる → 「AI向けZIPを出力…」。
   - クリックした手順は、既定で「押下時の画面」（ポインターを押した直後に取得を始めた画像）と「操作後の画面」を切り替えて見られます。
   - セレクターの指定や手順の追加では「画面プレビューで確認」から、記録した画像と DOM の上で、どの要素を指すかを確認・クリックで選択できます（外部へ通信せず、ページのスクリプトも動かしません）。
   - 再生パネルの「URL の置き換え（再生時）」で、記録した URL の先頭部分を再生のときだけ別の環境の URL に置き換えられます（記録は書き換えません）。

詳しくは [docs/guide.md](docs/guide.md) を参照してください。

## 5. 既知の制限（要点）

- **別オリジンへ遷移すると権限が失効します。** パネルに「記録が中断しています」と表示され、通知ステップが残ります。対象タブで TraceLens アイコンをクリックするか `Alt+Shift+S` を押すと継続します。失効中の操作は記録されません。複数オリジンをまたぐ調査では、パネルの「アクセス権について」から全サイトへのアクセスを任意で許可できます。
- 新しいタブ・別ウィンドウへの記録継続は任意設定（既定は無効）です。有効でも、同時に記録するのは 1 タブだけです。アクセス権のないタブは、そのタブでアイコンをクリックするまで切り替わりません。
- 画像は表示領域が基本です。ページ全体（スクロール合成）と要素単位の画像は任意の操作で取得しますが、固定ヘッダーの重複や遅延読み込みで実際の見た目と一致しないことがあります。ウィンドウ自体がスクロールしないページは全体を取得できません。
- 再生は `isTrusted` でないイベントを使うため、信頼されたイベントだけに反応するページでは効かないことがあります。ファイル選択、機密欄への入力、人が行う手順は人が操作します。alert・confirm で止まると失敗になります。
- 再生の「ok」は「操作を実行し、待機条件を観測できた」の意味で、業務処理の完了や成功ではありません。
- クロスオリジン iframe（権限のないもの）、closed Shadow DOM、canvas の内部、ブラウザ内部ページは取得できません。
- 画像内の文字は自動でマスクされません。出力前に人間が確認してください（塗りつぶし・ぼかし・切り抜きで手作業の対応はできます）。
- UI は日本語（既定）と英語を切り替えられます。出力 ZIP と保存データ由来の文言は、言語設定にかかわらず日本語です。
